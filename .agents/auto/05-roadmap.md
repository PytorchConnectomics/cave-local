# Bounded implementation sequence

This is a proposed sequence, not a scheduled commitment or authorization to launch jobs. DW owns scientific acceptance; implementation is assigned when work begins. Review at each milestone and, if work is active without progress, by 2026-10-25.

| Stage | Concrete output | Exit / stop condition |
|---|---|---|
| 0. Freeze the evidence | Validate voxel/partition reconstruction from the located pre-review x1 input; preserve the October 17 snapshot and reconcile October 19 review/point changes; record excluded bad references and inferred NML edges; reserve new test data | Stop end-to-end claims if pre-review input or registration cannot be established; continue bounded decision analysis |
| 1. Offline candidate and evidence harness | Deterministic candidate IDs, raw multiview packets, geometry, exact coordinates and dependency hashes; replay curated cases without writes | Coverage and repairability ceiling quantified; no reference-derived model inputs |
| 2. Minimal graph checker | Typed merge/split proposals, independently checked exact effects, constrained anchors and explicit failure classes | All adversarial graph fixtures pass; stop on crop-local “proofs” that miss global paths |
| 2b. Reusable morphology obligations | Two or three scoped inference rules, competing hypotheses, explicit missing observations, premise DAG and invalidation; worked continuation and branch examples | Same-evidence comparison against a flat scorer shows value; no noisy claim silently becomes a trusted axiom |
| 3. Cheap baseline and Qwen comparison | Rules, specialist and exact Qwen adapter; bounded calls, measured usage, frozen development calibration | Report actual cost/quality tradeoff; if Qwen adds no benefit, use specialist automation and retain VLM only where justified |
| 4. Sequential disposable replay | Exact simulation/commit, idempotency/reconciliation, postchecks, rollback dependency handling and cache invalidation | No unresolved transaction mismatch; compare final reconstruction and reviewer work, not only per-question scores |
| 5. Human recommendation pilot | CAVE review links with raw evidence, proposed effect, uncertainty and one-step adjudication | Recommendation gate in evaluation protocol passes; audit unknown and low-ranked cases |
| 6. Bounded automatic edits | Calibrated eligible subset, all-writer graph/claim consistency, concrete per-action and cumulative rollout harm limits | Both per-action and final-reconstruction harm gates pass; stop automatic writes on drift, postcheck failure or unknown commit |
| 7. Generalization and optional learning | New specimen/modality evaluation; local adaptation; possible learned view policy or formal Lean kernel | Add complexity only when ablations improve quality/cost; preserve failed experiments |

## First implementable slice

One candidate type, one reviewed cell class, one fixed snapshot, one renderer, one visual decision schema, and a small graph checker. Prefer contact-based false-split repair with curated separation constraints for the first executable slice; separately inspect whether enough trustworthy examples exist. Run false-merge diagnosis in parallel as recommendations because split execution has additional representation/preview dependencies. This choice is a testable scope decision, not a claim that merges are intrinsically safe.

Proposed code modules, to be created only during implementation: `auto/contracts`, `auto/cave_adapter`, `auto/evidence`, `auto/candidates`, `auto/checker`, `auto/models`, `auto/replay`, `auto/evaluate`. Use the repository's eventual packaging conventions; these names are not existing import paths or CLI commands.

## Dependencies that must remain visible

- Voxel-level validation of located pre-review x1 input and atom lineage through the v2 rebuild.
- Case-level outcomes for the 42 now-reviewed suspicious roots, provenance of annotation-linked partners, exact exclusions for bad references and treatment of generated gap edges. Both x1/x2 now inform development.
- Full physical alignment among raw microscopy, exported labels and comparison predictions.
- Reconciled native successful/failed/reversed operations and trusted negatives.
- Shared exact split planner for preview and commit; expected-state checks within the write boundary.
- Separate supervoxel refinement capability for within-atom merge errors. Do not silently change source atomization while measuring an agent improvement.
- Exact model endpoint/runtime and the allowed inference-data destination. Preserve Next versus hosted Flash identity and record actual costs.

## What can wait

A general neurobiology ontology, unrestricted agents controlling the viewer, distributed orchestration, large-scale RL, a new foundation model, and formalizing all biological claims in Lean. They are not prerequisites for the first falsifiable experiment. Small formal kernel proofs can proceed once semantics stabilize and their maintenance benefit is clear.

## What would falsify the proposal

If the morphology layer does not reduce damaging decisions or reviewer work at matched coverage/cost, the added abstraction is not justified. If the VLM is dominated by the specialist, use the specialist. If candidate recall or indivisible atoms dominate error, improve those before scaling model inference. If labels/registration cannot support an independent evaluation, fix the dataset contract before making accuracy claims.

Planning deliverable is complete when the research evidence, exact interface gaps, dataset provenance and testable milestones are recorded and reviewed. Implementation completion is a separate future result with measured evidence.
